RTSP to Web Gateway Guide (e.g. V380 Pro / IP Cameras)

Why can't browsers play RTSP directly?
Browsers (Chrome, Firefox, Edge) do not natively support raw RTSP protocols. Standalone Wi-Fi cameras like the V380 Pro or ONVIF IP cameras typically output an RTSP stream (e.g. rtsp://192.168.1.50:554/live/ch0).

Recommended Solution: MediaMTX or go2rtc Gateway

  1. Download the lightweight single-binary gateway MediaMTX (open source, zero install) or go2rtc.
  2. In mediamtx.yml, add your camera path: 
    paths:
  trinetra_cam:
    source: rtsp://admin:password@192.168.1.50:554/live/ch0
  3. Run mediamtx.exe. It automatically exposes an instant browser-compatible stream at:
    http://localhost:8889/trinetra_cam/ (WebRTC / HLS / MJPEG).
  4. Paste that URL into the Configure Stream modal on this page!
