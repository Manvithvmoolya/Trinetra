RTSP to Web Gateway Guide (e.g. V380 Pro / IP Cameras)

Why can't browsers play RTSP directly?
Browsers (Chrome, Firefox, Edge) do not natively support raw RTSP protocols. Standalone Wi-Fi cameras like the V380 Pro or ONVIF IP cameras typically output an RTSP stream (e.g. rtsp://192.168.1.50:554/live/ch0).

Integrated Solution: MediaMTX Gateway (Included in mediamtx/)

  1. Click "▶ Start Gateway" above (or run mediamtx/start_mediamtx.bat).
  2. In mediamtx/mediamtx.yml, customize your camera's RTSP source URL: 
    paths:
  trinetra_cam:
    source: rtsp://admin:password@192.168.1.50:554/live/ch0
  3. MediaMTX automatically serves the stream to your browser at:
    http://localhost:8889/trinetra_cam/ (WebRTC sub-second latency).
  4. Click the "🚀 WebRTC" button above to connect immediately!
