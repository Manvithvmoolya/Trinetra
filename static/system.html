ESP32 / Arduino Wi-Fi Integration Guide & Firmware
FIRMWARE READY

The Trinetra backend is configured to accept JSON payloads directly from your ESP32 or Arduino Wi-Fi module.

Important Local Network Configuration:
Microcontrollers cannot reach your computer via 127.0.0.1 or localhost (that points to the ESP32 itself).
1. Run ipconfig in Windows PowerShell to find your computer's IPv4 address (e.g. 192.168.1.150).
2. Ensure your computer and ESP32 are connected to the same Wi-Fi network.
3. Set the server endpoint in the ESP32 code to: http://<YOUR_LAPTOP_IP>:8000/api/sensors

Example Arduino C++ Telemetry Loop: 

#include <WiFi.h>
#include <HTTPClient.h>

const char* ssid = "YOUR_WIFI_SSID";
const char* password = "YOUR_WIFI_PASSWORD";
const char* serverUrl = "http://192.168.1.150:8000/api/sensors";

void sendTelemetry(bool metalDetected, float signalStrength, float battVoltage) {
  if (WiFi.status() == WL_CONNECTED) {
    HTTPClient http;
    http.begin(serverUrl);
    http.addHeader("Content-Type", "application/json");

    String jsonPayload = "{\"device_id\":\"trinetra-01\","
                         "\"metal_detected\":" + String(metalDetected ? "true" : "false") + ","
                         "\"signal_strength\":" + String(signalStrength, 1) + ","
                         "\"battery_voltage\":" + String(battVoltage, 2) + ","
                         "\"battery_percentage\":85.0,"
                         "\"motor_status\":\"nominal\","
                         "\"is_simulated\":false}";

    int httpCode = http.POST(jsonPayload);
    http.end();
  }
}
